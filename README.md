# 🚀 RozgarSaathi – Hyperlocal Daily Gig Platform

---

## 📌 Project Title

**RozgarSaathi**

---

## 📖 Description

RozgarSaathi is a hyperlocal job platform that connects daily wage workers (plumbers, electricians, painters, mazdoors, etc.) with nearby job opportunities in real-time.

It eliminates the need for workers to wait at physical nakas by providing **instant job visibility, skill-based matching, and direct communication** between workers and employers — with **no middleman and no commission**.

---

## ❗ Problem Statement

Daily wage workers — plumbers, electricians, painters, mazdoors — lose work days standing at nakas with zero digital visibility. Build a hyperlocal daily gig board where workers register with skill tags and availability, and households or contractors post same-day jobs with location. No middleman, no commission.

---

## 💡 Solution

RozgarSaathi enables a **simple and effective workflow**:

### 🔄 How it Works

1. 📝 **Register for Free**
2. 🔐 **Verify Identity (Aadhaar OTP – Mock)**
3. 📍 **Get Matched with Nearby Jobs (Geo + Skill Based)**
4. 💬 **Connect Instantly via WhatsApp / Call**

---

## ✨ Features

### 🔍 Core Features

* 📍 **Geo-based Job Feed** (jobs within 2–5 km radius)
* 🛠️ **Skill-based Filtering**
* 💬 **WhatsApp-style Contact Flow**
* ✅ **Verified Worker Badge (Aadhaar OTP Mock)**
* 🟢 **Worker Availability Toggle**

---

### ⚡ Advanced Features

* 🔄 Real-time job updates using Socket.io
* ⏳ Auto-expiring jobs (24-hour validity)
* ⭐ Worker rating system (backend ready)
* 📊 Dashboard stats (total workers, jobs, verified users)
